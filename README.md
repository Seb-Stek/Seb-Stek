### Featured project

**[Dark Nights Project](https://seb-stek.github.io/DarkNightsProject/)**: a concept site for a nonprofit that organizes monthly neighborhood light switch-offs so people can go outside and see the stars.

- Interactive light pollution simulator for the Bortle scale
- Live, zoomable map of upcoming Dark Nights
- An illustrated street you can switch off to watch the Milky Way appear
